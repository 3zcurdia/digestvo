El producto se anuncia como la referencia oficial de límites de ZIP Code para
mapeo, marketing y logística, y el hilo arrancó comprobando en el formulario de
pedido que el precio arranca en 10,000 dólares. El consenso técnico es que un
ZIP Code nunca fue un área geográfica: es una colección de direcciones y rutas
de entrega, de modo que estar dentro del polígono no garantiza ese código, y un
ZIP puede ser un punto o solaparse con otro, como muestran el Pentágono con
varios códigos y la Casa Blanca con uno solo. Sin embargo, el debate central es
si la información debería ser gratuita: la licencia prohíbe redistribuirla,
alguien propuso un GoFundMe para comprarla una vez y publicarla, y otros
replican que el valor del dataset es exactamente ser oficial y estar
actualizado, de modo que un espejo en GitHub arruinaría el punto; aun así, para
la mayoría basta con los ZCTA del censo, gratuitos y suficientemente buenos, y
una comparación con la muestra de Puerto Rico mostró diferencias pequeñas entre
ambas fuentes. Como nota menor, una rama discute las finanzas del USPS y si el
correo basura las empeora o las sostiene.
