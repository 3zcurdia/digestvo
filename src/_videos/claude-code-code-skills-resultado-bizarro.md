The argument worth taking is that scaffolding beats model choice. He hands the identical prompt to both systems and the difference is not subtle, but the reason is that one side received a written procedure and the other received a sentence. The most transferable idea is the skill as a plain file that any editor can call, since it costs nothing to try on your own repo. The part to discount is the visual-look argument, which is a proxy for effort rather than a measurement of quality.
