# Digest style guide

Use this structure for the "take" section of every digest post.

## Arc
Order points as follows:
1. **Contexto** - What sparked the discussion (the news/event). 1 paragraph, factual.
2. **Consenso** - What most commenters agreed on. Group related points.
3. **Controversia principal** - The central tension/debate. Give this the most space. Use transitions ("Sin embargo", "Aun así") to show hierarchy.
4. **Notas menores** - Tangents, jokes, side debates. Explicitly frame as minor ("Como nota menor", "Un detalle menor") and keep them short. Omit if not worth including.
5. **Cierre (opcional)** - Overall sentiment only if it naturally resolves.

## Rules
- **One idea per paragraph** when phases are distinct.
- **Hierarchy matters** - Don't give tangents equal weight to the main debate.
- **Be specific** - Name benchmarks, config flags, prices, numbers.
- **No commenter lists** - Don't enumerate every commenter; describe positions.
- **No "the thread was divided"** - Show the split explicitly.
- **Don't open with "The thread"** - Start with context.
- **Preserve hedges** - Keep uncertainty as written.
- **Language** - Write in Spanish as the site does.
