summary: >-
  OpenCode 2.0 is an overhaul of the open-source coding agent. Its
  client/server model now runs as a single background daemon that the TUI, web
  interface, and desktop app all connect to, and a rebuilt API ships with a
  new @opencode/client package plus an SDK for embedding OpenCode as a
  library. A key feature is Code Mode: a JavaScript interpreter that converts
  MCP servers and OpenAPI endpoints into composable functions, letting the
  agent call a dozen tools in a single scripted round trip. Background
  subagents and async shell commands, a hot-reloadable plugin system, and
  per-subagent model selection round out the release; 1.0 plugins and the old
  server API are breaking changes.

Most commenters land on 2.0 being a clear improvement, because the always-on
daemon finally makes remote sessions and multi-client setups first class, and
background subagents with per-subagent model choice are the everyday
quality-of-life wins people name unprompted. The sharpest objection is a
security regression: since every tool call now routes through the background
process, sandboxes built by wrapping the TUI process quietly stopped containing
the agent, so blocked web fetches started succeeding and it took some upgraders
days to notice. One commenter stacks further regressions on top, including
plugin hot-reloading that lets an agent modify its own plugins with immediate
effect and plugin-added tools that ignore permission configs. A secondary gripe
is the announcement site itself, a WebGL-heavy scroll experience that stutters
on M3/M4 MacBooks and Pixel phones.
